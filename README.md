# Fomo Fees & Referral Code JOIN2026: November 2026 Benchmark Hub

> Published by Fomo Referral Guide ([fomoappreferral.com](https://fomoappreferral.com/)), which is run by the owner of referral code `JOIN2026` and earns Fomo's referral commission on it. Not affiliated with Fomo or FOMO Labs.

Static HTML & CSV tables for Fomo (`fomo.family`) spot fees, Solana small-trade minimum bands, and referral code **`JOIN2026`** ([fomo.family/r/JOIN2026](https://fomo.family/r/JOIN2026)).

- **Any valid Fomo code:** the 0.50% spot fee becomes 0.45% (10% off).
- **`JOIN2026`:** the code owner returns 15% of the Fomo fee paid, in USDC (60% of the 25% referral share): **0.3825% net** on spot trades charged at the percentage rate (Solana trades of 190 USDC and up, and trades on the other chains).
- **Who pays and when:** the code owner, not Fomo, by in-app USDC Send: every Sunday once 25 USDC has accrued, and on the 1st of each month from 1 USDC; smaller balances roll over. The code must be on the account before the first trade.
- **Perps:** up to 0.05% of position size by Fomo plus Hyperliquid's own fee; no referral discount, no cashback; not available to US persons.
