FAQ

Do Fomo codes with "50" or "100" in the name give 50% or 100% off?

No. A Fomo referral link is fomo.family/r/ followed by the referrer's handle, so the characters in a code are a name, not a discount level. Per Help Center article 15171268, a referral code gives a 10% discount on the standard rate (0.50% to 0.45%). Anything beyond that, such as the 15% USDC cashback on JOIN2026, is paid by the code owner, not by Fomo.

Does JOIN2026 apply on iPhone, Android and the web?

Yes. The code is recorded on your Fomo account, and the same account works in the iOS app, the Android app and at fomo.family. The mobile app asks for a code when you log in, as long as no referrer is recorded and you have not traded; on the web, a code from a fomo.family/r/ link applies on its own after login. The 10% discount covers the standard spot rate on Solana and the seven other networks. Perps carry no referral discount and no cashback.
